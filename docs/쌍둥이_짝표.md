# 쌍둥이 짝 표

> B 작성 (11/15). 양식은 `docs/양식/B_시나리오카드.md` 6번. 길이는 본문 글자 수, 탐지 점수는 문자=링크 엔진(`/check`), 메일=이메일 엔진.
> 마지막 칸은 다른 팀원에게 둘 다 보여 주고 "어느 쪽이 더 쉬운가?"를 물어 적어요.

## 개인용 (P01부터 P08까지, 파일 `scenarios/personal_P01_P08.json`)

| pair | 세트 A | 세트 B | 유형(case_type) | 종류 | 단서 개수 A/B | 길이 A/B (글자) | 탐지 점수 A/B | 어느 쪽이 더 쉬운가 |
|---|---|---|---|---|---|---|---|---|
| 1 | P01 | P05 | A+C / A+C | 문자 | 3 / 3 | 93 / 88 | 20 / 20 | (팀원 확인) |
| 2 | P02 | P06 | A+B+C / A+B+C | 메일 | 3 / 3 | 73 / 82 | 0 / 0 | (팀원 확인) |
| 3 | P03 | P07 | 정상 / 정상 | 메일 | 3 / 3 | 94 / 85 | 0 / 0 | (팀원 확인) |
| 4 | P04 | P08 | 정상 / 정상 | 문자 | 3 / 3 | 73 / 77 | 0 / 0 | (팀원 확인) |

- 짝 1: 둘 다 학교 부서 사칭 + 계좌 요구 + 바깥 주소 + 시간 압박. 보낸 번호는 둘 다 학교 대표번호처럼 보이게(02-0000-0000) 해서 번호만 보고 못 맞히게 함
- 짝 2: 둘 다 학교 서비스 표시 이름 + 비슷하게 만든 바깥 주소 + 인증 통과(pass) + 비밀번호 요구. 엔진 점수가 둘 다 0점이라 사람이 "요구하는 행동"을 봐야 함
- 짝 3: 둘 다 학교 주소에서 온 정상 메일 + "오늘 …까지" 급한 말 + 평소 쓰는 시스템에서 직접 처리하라는 안전한 요구
- 짝 4: 둘 다 개인 번호(010-0000-0000)에서 온 정상 문자 + "오늘 안에" + 링크·결제·개인정보 요구 없음

## 기관용 (새 직군 카드 파일 `scenarios/org_S02B_S09B.json`)

| pair | 세트 A | 세트 B | 유형(case_type) | 종류 | 단서 개수 A/B | 길이 A/B (글자) | 탐지 점수 A/B | 어느 쪽이 더 쉬운가 |
|---|---|---|---|---|---|---|---|---|
| 1 | S01 | S10 | A+C / A+C | 문자 | 3 / 3 | 74 / 68 | 35 / 20 (A가 기관 단어에 court를 넣으면 35 / 35) | (팀원 확인) |
| 2 | S05 | S13 | 정상 / 정상 | 메일 | 3 / 3 | 139 / 142 | 0 / 0 | (팀원 확인) |
| 3 | S08 | S14 | 정상 / 정상 | 문자 | 3 / 3 | 75 / 74 | 0 / 0 | (팀원 확인) |
| 4 (인사) | S02 | S02B | A+C / A+C | 메일 | 3 / 3 | 89 / 95 | 83 / 83 | (팀원 확인) |
| 4 (재무) | S03 | S03B | A+C / A+C | 메일 | 4 / 4 | 136 / 145 | 10 / 10 | (팀원 확인) |
| 4 (영업) | S04 | S04B | B+C / B+C | 문자 | 3 / 3 | 60 / 66 | 55 / 55 | (팀원 확인) |
| 4 (개발) | S09 | S09B | A+C / A+C | 메일 | 4 / 4 | 83 / 90 | 62 / 62 | (팀원 확인) |
| 4 (일반 사무) | S07 | S07B | A+C / A+C | 문자 | 3 / 3 | 83 / 79 | 25 / 25 | (팀원 확인) |

- 짝 1 (S01·S10): 둘 다 기관 사칭 문자 + 개인 번호 + 비공식 주소 + 압박 문구. 링크 엔진의 공공기관 단어 목록(ORG_WORDS)에 health는 있고 court는 없어서 점수가 35 / 20으로 갈림. S10 링크를 /check로 바꿔 10 → 20으로 좁힘
- 짝 2·3: 기존 정상 카드끼리. 회사 주소·번호에서 와도 "요구하는 행동이 안전해서" 정상
- 직군 짝: 기존 카드의 수법·단서 구성·헤더 설정을 그대로 두고 이야기만 바꿈 (연말정산 → 성과급, 거래처 이름, 메신저 → 포털 판매자 계정, 코드 저장소 → 빌드 도구, 수사기관 → 세무 기관). 다섯 짝 모두 탐지 점수가 같음
