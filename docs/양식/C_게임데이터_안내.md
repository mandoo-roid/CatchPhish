## 1. 칸 7개

| 칸 | 넣는 값 | 예 |
|---|---|---|
| `sender` | 보낸 곳 | 택배사, 카드사, 엄마, OO은행 |
| `content` | 문자 한 줄 (카드에 두 줄 이내로 보이게, 25자 안팎) | 주소 불일치, 링크에서 수정 |
| `is_phishing` | 피싱 `1` / 정상 `0` | |
| `level` | 난이도 `1` 쉬움 / `2` 비슷한 문자 섞임 / `3` 같은 보낸 곳 짝 | |
| `reason` | 결과 화면에 보일 이유 한 줄 | 링크로 주소·개인정보를 입력하게 해요 |
| `method` | 피싱만: 수법 이름 (맞히면 뱃지로 뜸). 정상은 비우기 | 스미싱, 큐싱, 메신저 피싱, 보이스피싱, 로맨스 스캠, 파밍 |
| `source` | 근거 자료 이름과 주소 | 경찰청, 금융감독원, KISA 보호나라 등 |

## 2. 규칙

1. **40개 이상** (피싱·정상 비슷한 수). 적으면 같은 문자가 반복돼서 외워서 순위가 갈려요
2. **같은 보낸 곳 짝으로 만들기.** 피싱 하나 쓰면 같은 보낸 곳의 정상도 하나 (예: 카드사 피싱 ↔ 카드사 정상). 이 게임의 핵심이에요
3. 짝의 차이는 **"무엇을 하라는지 + 어디서 확인하라는지"** (링크·문자 속 번호 vs 공식 앱·대표번호)
4. 난이도: 1은 누가 봐도 구분되는 것, 3은 짝끼리 겉모습이 거의 같은 것. 각 난이도에 골고루
5. **애매한 것은 빼기.** 상황에 따라 정상일 수도 있는 문구는 피싱 쪽에 넣지 않기
6. **출처 없는 피싱 문구는 넣지 않기.** 실제로 쓰인 수법인지 공식 자료로 확인
7. 번호·링크 주소는 쓰지 않기 (문구로만 "이 번호로", "링크에서"). 기관 이름은 써도 되지만 로고는 안 씀
8. 전문 용어 퀴즈가 아니라 **생활에서 실제로 받는 문자**로

## 3. 짝 예시 (표에 이미 들어 있음)

| 보낸 곳 | 피싱 | 정상 |
|---|---|---|
| 택배사 | 주소 불일치, 링크에서 수정 | 배송 완료, 문 앞에 두었어요 |
| 카드사 | 해외 결제 승인, 문의는 이 번호로 | 결제 완료, 자세한 건 카드 앱에서 |
| 엄마 | 폰 고장, 친구 폰이야. 상품권 좀 사 줘 | 저녁 먹고 들어와 |

더 넣을 만한 보낸 곳: 은행, 국세청·구청 같은 기관, 중고거래, 쇼핑몰, 학교, 병원, 친구, 통신사, 택배 보관함
