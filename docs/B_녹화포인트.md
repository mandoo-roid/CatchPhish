# B 녹화포인트 (영상 1분)

B 파트(이메일 헤더 배점, 게임 시나리오·화면)의 영상 장면이에요. 3분 영상 전체의 "문제 → 과정 → 성과"와 초기·중기·완성 흐름에 맞춰 6장면, 약 60초로 골랐어요. 장면 선정과 자막 초안은 Claude가 추천했고, 실제로 쓴 파일과 자막은 B가 확정했어요.

## 자막

자막의 숫자와 표현은 저장소 내용과 팀 결정(인수인계서 8번)에 맞췄어요.

| # | 자막 |
|---|---|
| 1 | 이메일 헤더 인증 결과로 위험도 산정 · DMARC 28 · SPF 17 · DKIM 0 / DKIM은 정상 메일에서도 자주 깨져 오탐을 줄이려고 0점 |
| 2 | AI 초안을 실제 피싱 사례(사례 5)와 단계별로 대조 / 사례와 다른 3곳을 직접 고쳐 확정 |
| 3 | 실제 업무 환경과 비슷하게 만든 가상 화면 / (특정 서비스의 로고·이름·디자인은 쓰지 않음) |
| 4 | 진짜 업무 메시지도 섞었어요 · 공통 4 + 직군 1 = 5문제 중 정상 2개 / 모두 의심하면 '업무 지연'으로 따로 기록 |
| 5 | 연쇄형 피싱: 문자 → 가짜 앱 설치 페이지 → 가짜 PDF 뷰어 / 한 번 누르면 다음 함정으로 이어져요 / 몇 단계에서 멈췄는지까지 기록 · 첫 단계에서 멈추는 연습 |

자막 칸의 `/`는 줄바꿈 자리예요.

## 편집 메모

- 자막 한 줄은 20자 안팎, 한 줄당 2초 이상
- 클릭으로 넘어가는 부분은 1.5배속에서 2배속, 해설·배너가 나오는 순간만 보통 속도
- 6번 끝의 노란 배너는 2초쯤 멈춤 화면
- 학번, 이메일, 계정 사진, 회사 코드, Claude 왼쪽 대화 목록, 즐겨찾기 줄이 보이면 흐림 처리
- "전" 영상이 없으면 4번만 쓰고 자막을 "실제로 받은 것 같은 화면으로 바꿨어요"로 바꿈 (없는 장면을 새로 찍어 "전"처럼 쓰지 않음)
