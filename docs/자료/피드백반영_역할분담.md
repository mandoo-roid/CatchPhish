## 1. 방향

- 캐치피싱은 **회사원이 피싱 메일·문자를 직접 겪어 보며 교육받는 프로그램**이에요. 업무 중에 짧게 받는 교육이라, 이번에는 게임을 만들지 않고 **체험이 더 잘 전달되도록** 다듬어요.
- 교수님이 말씀하신 게임 아이디어(카드 짝맞추기, OX 퀴즈, 퍼즐 등)는 `교내전시회_게임아이디어_참고.md`에 모아 두었어요. 교내 전시회 때 참고해요.
- 목표는 그대로예요. "모두 의심하기"가 아니라 **"보낸 곳과 요구하는 행동을 보고 근거 있게 판단하기"**.

### 맞물리는 약속

**`scenarios.json`에 B가 추가하는 칸 (시나리오마다)**

```json
"choice_labels": {
  "click": "첨부된 연말정산 파일을 열어 바로 제출한다",
  "call": "메일에 적힌 번호로 전화해 물어본다",
  "official": "처리를 멈추고 인사팀 사내 연락처로 확인한다"
},
"explanation_short": "인사팀 이름을 빌린 바깥 주소 메일이에요. 첨부를 열지 말고 사내 연락처로 확인하세요."
```

- 키 이름 `click`, `call`, `official`은 채점에 쓰여서 **그대로** 둬요. 문구만 시나리오에 맞게 바꿔요
- 기존 `explanation`은 그대로 두고 [자세히 보기] 안에 들어가요
- (선택) 피싱 시나리오에 `"consequence": {"title": "급여 계좌가 바뀌었어요", "detail": "..."}`를 쓰면, 속았을 때 해설 맨 위 "실제였다면" 한 줄에 그 문구가 나와요. 없으면 고른 행동에 맞는 기본 문구가 나와요

**C가 만드는 함수**

```python
def get_badge(blocked_phish, total_phish, done_normal, total_normal):
    # 반환 예: {"level": 3, "name": "어린 나무", "title": "보안 레벨 3", "message": "피싱은 모두 막았어요. 정상 업무도 처리하면 다음 레벨이에요."}
```

- `blocked_phish/total_phish` = 막은 피싱, `done_normal/total_normal` = 처리한 업무 (지금 결과 화면의 두 점수와 같은 값)

**파일 위치**

| 무엇 | 위치 | 만드는 사람 → 쓰는 사람 |
|---|---|---|
| 안내 화면 | `game.html`의 `intro-screen` | B → A가 순서 연결 |
| 선택지·요점 문구 | `scenarios.json`의 `choice_labels`, `explanation_short` | B → A가 표시 |
| 뱃지 규칙 | `backend/db_logs/badge.py`의 `get_badge()` | C → A가 연결 |
| 뱃지 그림 | `frontend/badges/lv1.svg` ~ `lv4.svg` | B → A가 표시 |
| 로고·아이콘 | `frontend/img/` | B → A가 표시 |
| 보안 매뉴얼 | `frontend/manual.html` | B가 만들고 A가 주소 설정 |

## 4. 팀이 정할 것 📌

- **로고:** 시안 중 하나 고르기
- **뱃지 모양:** 자물쇠와 나무 중 하나 (둘 다 쓰면 화면이 복잡해져요)
- **레벨 기준:** C가 초안을 만들고 셋이 확인. 아래는 출발점이에요.
  - 레벨은 **두 점수(막은 피싱, 처리한 업무)를 함께** 봐요. 모든 메시지를 멈춰서 막은 피싱만 만점인 경우는 최고 레벨이 되지 않게 해요. 우리 목표가 "근거 있게 판단하기"라서요.
  - 예시: 1단계 새싹(막은 피싱이 절반 미만) → 2단계(막은 피싱 절반 이상) → 3단계(막은 피싱 만점) → 4단계 나무(두 점수 모두 만점)
- **보안 매뉴얼:** 지금 있는 페이지인지, 새로 만들어야 하는지 확인. 새로 만들면 내용은 해설과 사례조사에서 가져와요

## 5. 같이 작업할 때 지킬 것

- **A와 B가 `frontend/game.html`을 동시에 고쳐요.** 고치기 전에 항상 저장소 최신 파일을 받고, 작은 단위로 자주 커밋해요. B는 화면 모양(스타일·화면 구조), A는 동작(스크립트) 위주로 고쳐서 겹치는 곳을 줄여요
- 시나리오 선택지를 바꾸면 채점에 영향이 있어요. `scenarios.json`을 고친 뒤 단톡에 알려 주세요
- 기존 장부(해시체인)와 관리자 통계 계산은 건드리지 않아요
- 로고·아이콘·뱃지 그림을 AI로 만들었으면 "AI 생성 이미지"로 표시하고, AI 활용 기록표에 적어요. 다른 캐릭터나 로고를 닮게 만들지 않아요
- 커밋 메시지 앞에 담당을 적어요 (예: `[B] 체험 시작 안내 화면`)
