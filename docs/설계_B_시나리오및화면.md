## 1. 시나리오 카드 양식

게임에 나오는 메일·문자·링크 한 개를 아래 칸으로 적는다.

| 칸 이름(임시) | 뜻 | 예시 | 비고 |
|---|---|---|---|
| scenario_id | 카드 번호 | S01 | |
| type | 종류: email / sms / url | email | sms는 결과 형식(type)에 없는 값이라 팀 확인 필요 |
| job_group | 어느 직군용인지 | 인사 | 직군 목록은 팀 결정 후 확정 |
| is_phishing | 피싱이면 true, 정상이면 false | true | |
| sender | 보낸 사람 (이름과 주소) | 인사팀 <hr@company-notice.example> | 연습용 .example 주소만 사용 |
| subject | 제목 (문자는 빈칸) | [긴급] 연말정산 서류 제출 | |
| body | 본문 | (본문 문장) | 실제 회사·사람 이름 쓰지 않기 |
| link | 본문 속 링크 (없으면 빈칸) | https://hr-check.example/login | 접속하지 않음. 분석만 함 |
| clues | 수상한 점 목록 (해설용) | 아래 표 참고 | A의 reasons와 비슷한 모양으로 |
| explanation | 정답 해설 | (2~3문장) | 쉬운 말로 |
| source | 참고한 사례 | 사례조사 #번호 | 실제 사례를 그대로 베끼지 않고 바탕으로만 사용 |

clues 한 줄은 `이름(factor)` 과 `설명 문장(text)` 으로 적는다.
