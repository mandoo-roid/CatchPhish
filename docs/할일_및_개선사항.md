## 1. 게임 시작 전 안내문 바꾸기 (팀 논의에서 나온 안)

문제: 참가자가 "피싱 예방 체험"이라는 걸 알고 시작하면, "나는 안 속아" 하는 마음으로 모든 메시지를 의심해서 실제보다 결과가 좋게 나온다. 지금 시작 화면의 **"가짜 메일·문자·링크가 6개 나옵니다"**라는 문구가 오히려 의심을 부른다.

- [ ] 시작 화면 안내문을 "평소처럼 행동하라"는 문구로 바꾸기
  - "가짜"라는 말 빼기
  - 정상 메시지도 섞여 있다고 미리 알리기
  - 모두 의심하면 업무 지연으로 기록된다고 알리기
- [ ] 문구 확정 (B와 다듬기) → 정해지면 `frontend/game.html`의 시작 화면 문구만 바꾸면 됨

안내문 예시 (초안):

> **평소 업무 중이라고 생각해 주세요.**
> 회사에서 받은 것 같은 메일과 문자 6개가 차례로 나와요. 진짜 업무 메시지도 섞여 있어요.
> 평소에 하던 대로 골라 주세요. 모든 메시지를 의심하면, 확인하느라 업무가 늦어진 것으로 기록돼요.

발표·작품설명서 소재: "체험임을 알면 결과가 좋게 나오는 한계를 발견하고 안내 방식으로 보완했다" (문제 해결 과정의 독창성)

## 2. 피싱 시나리오 위험 점수 보완 (A)

문제: 링크 주소만 분석해서 일부 피싱 시나리오 점수가 낮다 (예: S01 건강보험 35점). 본문의 압박 표현은 아직 점수에 안 들어간다.

- [ ] **이메일 검사기 웹용으로 연결** → 이메일 시나리오 S02·S03·S05에도 해설 점수가 나오게
- [ ] **본문 긴급성 키워드 항목 추가** ("오늘 중", "불이익", "즉시", "벌금" 등, 사례조사 유형 C). 배점은 팀 논의 (링크 배점 합계 100을 다시 나눠야 함)
- [ ] 그래도 낮으면 엔진 기준 조정 (기관 이름 목록, 키워드 목록)
- [ ] 규칙: 시나리오를 새로 만들면 링크를 엔진에 넣어 점수 확인
