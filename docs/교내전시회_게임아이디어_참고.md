# 교내 전시회 게임 아이디어 (참고용)

> 쓴 사람: A · 11/2
> **참고용 파일이에요.** 반드시 만들어야 하는 목록이나 역할 분담이 아니에요. 교내 전시회 버전을 만들 때 아이디어를 꺼내 보는 용도예요.

---

## 1. 왜 공모전 제출본에는 넣지 않나요

캐치피싱의 본질은 **회사원이 피싱 메일·문자를 직접 겪어 보며 교육받는 프로그램**이에요. 회사원은 업무 중에 시간을 내서 교육받기 때문에, 공모전 제출본에는 짧고 가벼운 반복 학습만 넣어요.

반면 교내 전시회는 관람객이 부스에서 잠깐 즐기고 가는 자리라, 아래 같은 게임 요소가 잘 맞아요.

## 2. 교수님 피드백 중 게임 관련 내용 (11/2)

- 지금은 게임 같지 않음 (시험 같고, 그냥 학습 도구 같음)
- 글자 조합, 스피드 퀴즈, OX 퀴즈, 퍼즐 맞추기 등으로 반복 학습 효과를 높일 것
- **카드 짝맞추기**를 교육 효과가 가장 좋았던 예로 보여 주심
- 앞에서 나온 결과 값을 보고 OX 퀴즈나 스피드 퀴즈 진행, 순위 정하기 (보상 체계)
- 인식 게임 (타자 연습 같은 형식), 경각심을 주는 문구
- 가로세로 퍼즐
- 집중도를 올리기 위한 보상 체계
- 캐릭터를 넣는 등 예쁜 UI, 아이콘, 게임 모드 프레임 나누기 (레트로), 배경이 모니터

## 3. 게임 아이디어

| 게임 | 하는 방법 | 우리 목표와 맞추는 방법 |
|---|---|---|
| 편지봉투 열기 (예시) | 단어나 문구가 적힌 편지봉투를 골라 열면, 피싱이면 **악마**, 정상이면 **천사**가 나옴 | 봉투에 "오늘 안에 확인", "비밀번호 재설정"처럼 요구하는 행동을 적어서, 무엇을 보고 판단하는지 연습. 천사(정상) 봉투도 섞기 |
| 카드 짝맞추기 | 피싱 수법 카드 ↔ 알아보는 방법 카드 짝 맞추기 | 교수님이 교육 효과가 가장 좋았다고 보여 주신 방식. 수법마다 "어디를 보면 알 수 있는지"를 짝으로 |
| OX·스피드 퀴즈 | 제한 시간 안에 O/X. 빨리 맞힐수록 점수 | 체험 결과에서 많이 틀린 유형을 먼저 냄. 정상 문제도 넣어 "모두 X"로는 이길 수 없게 |
| 글자 조합 | 섞인 글자 조각으로 보안 용어 맞추기 (예: 싱·스·미 → 스미싱) | 용어를 외우는 것보다 뜻(힌트)을 읽게 하기 |
| 가로세로 퍼즐 | 보안 용어 6~8개로 작은 퍼즐 | 힌트를 "이런 메일이 오면 무엇을 확인하나요" 같은 상황 문장으로 |
| 타자 연습 | 경각심 문구 따라 치기 | 공모전 제출본에는 가벼운 버전으로 들어감. 전시회에서는 속도 순위를 붙일 수 있음 |

## 4. 보상 체계 아이디어

| 방식 | 어떻게 |
|---|---|
| 순위표 | 게임별 점수 순위를 나열 (상위 10명 + 내 등수). 별명으로만 저장 |
| 기준 점수 보상 | 전시회에서는 체험하고 바로 떠나는 사람이 많아, 모두 끝날 때까지 기다렸다 순위대로 보상할 수 없음. **기준 점수를 넘으면 바로** "보상 기준 통과" 화면을 띄우고, 부스에서 그 화면을 보고 보상을 줌 |

- 점수는 맞힌 개수가 먼저, 빠르기 보너스는 맞힌 문제에만 (아무거나 빨리 눌러 보상받지 않게)
- 기준 점수는 그때 팀이 정함

## 5. 화면 아이디어

- 첫 화면 맨 밑에 [게임 시작] 버튼 → 게임 모드 고르는 화면
- 옛날 모니터 테두리 안에 게임이 나오는 레트로 화면
- 캐치피싱 캐릭터가 안내, 게임별 아이콘

## 6. 만들게 되면 지킬 것

- 실명·학번을 받지 않아요. 순위표는 별명만
- 캐릭터·아이콘은 직접 만들거나, AI로 만들면 "AI 생성 이미지"로 표시해요. 다른 게임·만화 캐릭터를 닮게 만들지 않아요
- 게임 점수는 체험 장부(해시체인)와 관리자 화면의 체험 통계에 섞지 않아요
- 주소 예시는 `.example` 연습 주소만 써요
- 문제 파일은 기존 시나리오와 같은 유형 이름(기관 사칭, 도메인 위조, 심리 압박, 연쇄형, 정상)을 쓰면, 체험 결과와 이어 붙이기 쉬워요
