## 1. 오늘은 왜 "설계"를 하나요?

집을 지을 때 벽돌부터 쌓지 않죠. 먼저 **설계도**를 그려요. 방이 몇 개인지, 문은 어디에 있는지, 전기선은 어디로 지나가는지 정해 두어야 목수, 전기 기사, 페인트공이 **동시에** 일해도 집이 맞아떨어져요.

우리도 똑같아요. 오늘 3시간 동안 설계도를 그려 두면, 다음부터는 세 사람이 서로 기다리지 않고 각자 자기 부분을 만들 수 있어요.

### 우리가 만들 것을 한 문장으로

> 회사 직원이 **가짜 메일·문자·링크가 나오는 게임**을 하면서, 속았을 때 **"왜 위험했는지" AI가 설명**해 주고, 그 기록이 **안전하게 저장**되어 회사가 **어느 부서가 어떤 피싱에 약한지** 볼 수 있는 웹 프로그램

1. **직군 목록:** 게임에서 고를 부서. 초안: 인사 / 재무·회계 / 영업·고객 / 개발·IT / 일반 사무
2. **행동 3개:** 추천안: ① 링크를 누른다(첨부를 연다) ② **메시지에 적힌 번호로** 전화해서 확인한다 ③ **공식 경로**(공식 앱, 대표번호, 사내 담당자)로 직접 확인한다. 피싱이면 ①② 속음, ③ 정답 / 정상이면 모두 정답이지만 ③은 '과잉 의심'으로 따로 세기. (②는 피싱 문자 속 번호로 거는 것 자체가 보이스피싱 함정이라서 이렇게 나눠요)
3. **링크 점수 기준 2개:** 하이픈(-) 1개부터 점수? 2개부터? / gov 하나로 두 항목 점수가 같이 붙는 게 괜찮은지
4. **이메일 배점:** 지금 SPF 실패 40, 보낸 사람 불일치 30은 임시값
5. **긴급성 키워드 항목:** "즉시, 벌금, 별세, 당첨" 같은 말을 점수에 넣을지 (사례조사 유형 C)
6. **만드는 방식 4가지:** 저장소 공개 유지 / 브랜치 없이 main에 바로 저장 / 화면은 React 대신 기본 HTML / 서버는 AWS 대신 무료 호스팅

## 5. 각자 할 일 (0:20~2:10)

### A: 진행 순서와 전달 규칙 (전체 흐름 + 서버 약속)

**무엇을:**
1. 손님(직원)이 보는 **화면 순서**를 정해요. 시작 안내 → 문진표 → 게임 → 결과 → 링크 직접 검사. 그리고 회사 담당자가 보는 관리자 화면.
2. **서버 약속**을 정해요. 화면이 서버에게 "이거 해 줘" 하고 보내는 부탁과, 서버가 돌려주는 대답의 모양이에요.

**왜:** 식당에서 홀 직원이 주방에 주문서를 넣을 때, 주문서 모양이 정해져 있어야 주방이 헷갈리지 않죠. 서버 약속이 그 **주문서 양식**이에요. 이게 있어야 B는 화면을, C는 저장을 서로 기다리지 않고 만들 수 있어요.

🎬 **녹화:** 화면 흐름 표가 완성됐을 때 Claude 화면 15초 (`1019_화면흐름.mp4`)

### B: 문제 카드와 부스 꾸미기 (시나리오 + 화면)

**무엇을:**
1. **시나리오 카드 양식**을 정해요. 게임에 나오는 메일·문자·링크 한 개를 어떤 칸으로 적을지(제목, 보낸 사람, 본문, 링크, 피싱인지 아닌지 등).
2. **시나리오 6개 초안**을 써요. 사례조사의 실제 사례를 바탕으로, **정상 메시지도 1~2개 섞어서**, 직군별로.
3. **문진표 질문 3~4개**와 **화면별로 무엇이 보이는지**(버튼, 문구) 정해요.

**왜:** 게임이 너무 쉬우면(누가 봐도 수상한 문자만 나오면) 교육 효과가 없어요. 진짜와 헷갈릴 만큼 현실적인 문제 카드가 이 프로그램의 핵심이에요. 그리고 카드 양식이 정해져 있어야 나중에 누구든 카드를 추가할 수 있어요.

🎬 **녹화:** 시나리오 한 개를 사례조사 PDF와 비교하며 쓰는 장면 20초 (`1019_시나리오설계.mp4`)

### C: 참가 기록부와 결과 게시판 (기록 + 통계)

**무엇을:**
1. **기록 한 줄의 양식**을 정해요. 직원 한 명이 문제 하나를 풀면 장부에 무엇을 적을지(익명 번호, 직군, 시나리오 번호, 고른 행동, 맞았는지, 시간 등).
2. **해시체인**으로 기록을 지키는 방법을 정해요. 각 기록에 "바로 앞 기록의 지문"을 같이 적어서, 누가 중간 기록을 몰래 고치면 지문이 안 맞아 바로 들키게 하는 방식이에요.
3. **관리자 게시판에 보여줄 통계**와 **맞춤 피드백 규칙**을 정해요. 직군별 오답률, 많이 속은 유형, 자가평가와 실제 결과의 차이 / "유형 B에 많이 속았다면 이런 팁" 같은 규칙.

**왜:** 교육 효과를 **숫자로** 보여주는 게 심사 점수(교육성과)에 직접 들어가요. 그리고 교육 기록을 아무도 몰래 고칠 수 없다는 걸 증명하는 게 우리 작품의 보안 포인트예요.

🎬 **녹화:** 기록 양식 표와 해시체인 설명이 나온 Claude 화면 15초 (`1019_기록설계.mp4`)
