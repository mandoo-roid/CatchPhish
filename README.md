# Phish&Chips · 캐치피싱(CatchPhish)

AI 기반 피싱 탐지 및 보안 교육 체험 플랫폼 (캡스톤디자인)

## 이 저장소는 무엇인가요?

팀원 3명(보안 A, B, C)이 **코드를 한곳에 모아 두는 보관함**입니다.
GitHub에 올린다고 웹사이트가 바로 열리지는 않고, 코드를 받아서 서버를 켜야 실행됩니다.

## 폴더 구조

아직 없는 폴더는 **처음 파일을 올릴 때 자동으로 만들어집니다.**

| 폴더 | 들어가는 것 | 담당 |
|---|---|---|
| `samples/` | 결과 모양 샘플 (지금 있는 것) | A |
| `backend/url_analyzer/` | 링크 점수 함수 | A |
| `backend/email_analyzer/` | 이메일 헤더 분석 | B |
| `backend/db_logs/` | 장부(DB), 해시체인, 통계 | C |
| `frontend/` | 화면 | B |
| `scenarios/` | 시나리오 파일 | 각자 1개씩 |
| `docs/` | 회의 메모 등 | 전원 |

**규칙: 자기 폴더의 파일만 고칩니다.** 다른 사람 폴더에서 고칠 게 보이면 직접 고치지 말고 단톡에 알려 주세요.

## 결과 형식 (samples/ 폴더)

링크든 이메일이든, 분석이 끝나면 **아래 칸 이름으로 결과를 만들어서 넘기자**는 약속입니다.
이어달리기의 바통 모양을 똑같이 맞추는 것과 같습니다.

```
A(링크 분석) ─┐
              ├─ 결과 ──→ B가 화면에 보여줌
B(이메일 분석)─┘        └→ C가 장부에 저장
```

### 칸 설명

| 칸 | 쉬운 뜻 | 만드는 사람 | 쓰는 사람 |
|---|---|---|---|
| `type` | 링크 검사인지 이메일 검사인지 (`url` 또는 `email`) | A, B | B, C |
| `input` | 검사한 것 자체 (링크 주소 또는 파일 이름) | A, B | B, C |
| `score` | 위험 점수 (0~100) | A, B | B, C |
| `model_probability` | AI 모델이 말한 피싱 확률 (0~1). 모델이 없으면 `null` | A | B, C |
| `reasons` | 점수가 나온 이유 목록 | A, B | B (화면), C (저장) |
| `unavailable` | 조사하려다 실패한 항목 (없으면 빈 목록 `[]`) | A, B | B, C |

### reasons 안의 칸

| 칸 | 쉬운 뜻 | 예시 |
|---|---|---|
| `factor` | 이유의 이름 | 도메인 유사 |
| `points` | 이 이유로 더해진 점수 | 35 |
| `text` | 사람이 읽는 설명 문장 | 유명 포털과 비슷한 도메인 이름 |

## 샘플 3개

| 파일 | 보여주는 것 |
|---|---|
| `url_dangerous.json` | 위험한 링크. 이유 2개, 모델 확률이 있는 경우 |
| `url_whois_fail.json` | 도메인 조회에 실패한 링크. 실패한 항목은 0점이 아니라 `unavailable`에 적고, 나머지로만 점수를 낸 경우 |
| `email_spoof.json` | 이메일 위조 의심. 모델이 없어서 `model_probability`가 `null`인 경우 |

## 약속 (초안, 팀 합의 후 확정)

1. `score`는 `reasons`의 `points`를 더한 값입니다. 샘플도 이 규칙으로 맞췄습니다.
2. 링크 점수 배점 초안: 도메인 유사 35 / 생성일 30 / 기관명 불일치 15 / 긴급 키워드 10 / URL 구조 10 (합계 100). 이메일 배점은 B가 정합니다.
3. 조회에 실패한 항목은 0점으로 처리하지 않고 `unavailable`에 적습니다. 그 항목 점수는 빠진 채로 계산되므로 실제 위험보다 낮게 나올 수 있습니다.
4. JSON 파일 안에는 `//` 같은 설명 줄을 쓸 수 없습니다. 설명은 이 README에만 적습니다.
5. **칸 이름을 바꾸거나 추가하려면** 단톡에 먼저 알리고, 아래 변경 기록에 한 줄 적습니다.

## 주의

- 샘플은 **가짜 데이터**입니다. 실제 분석 결과나 성과가 아닙니다.
- 샘플의 `.example` 주소는 문서용 예시입니다. 실제 분석 테스트에 쓸 URL은 따로 정합니다.
- 피싱 링크는 **분석만 하고 접속하지 않습니다.**
- API 키, 비밀번호는 절대 올리지 않습니다 (`.env`에만 적고 `.gitignore`에 `.env`를 넣습니다).
